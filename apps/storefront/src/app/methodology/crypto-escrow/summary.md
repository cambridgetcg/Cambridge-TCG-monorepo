# Crypto wallet + P2P escrow — TLDR

Cambridge TCG can verify control of a Base Sepolia wallet without taking its keys. The current build names only Circle's no-value test USDC and keeps checkout disabled. A submitted transaction is not payment: exact asset, amount, parties, settlement generation, terms digest, timely block inclusion, event success and finality must reconcile before fulfilment. Every release path then passes shipping, inspection and release eligibility.
