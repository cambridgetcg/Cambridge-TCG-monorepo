# PRISM Signals product flow — TLDR

**Free synthetic preview · optional Stripe test mode · no live market data · no real payment.** PRISM Signals by Cambridge TCG wraps the public opportunity-signal boundary in a branded reading: only coarse bands, evidence confidence, liquidity, risks, and fixed non-claims may cross. A separate signed-in path records revocable product-specific beta interest for at most 180 days; it is not general marketing consent, an invitation, payment, queue position, or access. Free remains the public fixed fixture with no entitlement. A separately gated All sandbox requires both active beta interest and an operator-issued, active, unexpired invitation, then uses a £5 monthly test amount and a dedicated signed Stripe host to rehearse Checkout, invoice-confirmed access, renewal, cancellation and repair as an owner-labelled projection around that same public fixture; it gates no unique payload. A full refund separately requires verified subscription cancellation before any later grant or account erasure. Checkout and browser return cannot grant; live Stripe events are rejected; raw provider ids stay in local mappings while the generic runtime sees opaque references. Stripe live mode, Telegram Stars, PayPal, crypto, production source rights, a live price, real charge, private delivery engine and outbound signal delivery remain off.
