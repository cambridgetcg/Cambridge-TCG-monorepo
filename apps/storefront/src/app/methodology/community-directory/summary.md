# Community directory — TLDR

The organisation directory lists only collectives whose steward made the separate, versioned directory-publication choice. Existing public profiles are not opted in retroactively. Public HTML and JSON may be indexed, copied or redistributed by search engines, AI crawlers and other third parties; withdrawal cannot recall those copies. Its public query selects no record id or structured/platform-derived steward or membership data, and stewards must not include personal data about another person in directory fields. Steward-written facts remain `NOASSERTION`; platform record timestamps are labelled separately and are not publication receipts. Results are alphabetically ordered, never ranked or inferred. Explicitly invalid API filters return 400, all fields/facets/pagination are bounded, and count plus rows share one database statement. Correction and removal requests go to `support@cambridgetcg.com`.
