# Community directory — TLDR

The organisation directory lists only collectives whose steward made the separate, versioned directory-publication choice. Existing public profiles are not opted in retroactively. Its public query selects no record id or structured/platform-derived steward or membership data; steward-written free text may mention people. Steward-written facts remain `NOASSERTION`; platform record timestamps are labelled separately and are not publication receipts. Results are alphabetically ordered, never ranked or inferred. Explicitly invalid API filters return 400, all fields/facets/pagination are bounded, and count plus rows share one database statement.
